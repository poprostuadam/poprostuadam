# Adam Stefaniak

Software developer focused on **data engineering**, **applied AI**, and building practical, well-documented applications.

I work across the full project lifecycle—from data ingestion and transformation to domain logic, user interfaces, testing, and continuous integration. My public projects include an automated air-quality data warehouse, computer-vision research, an AI cooking assistant, and applications written in Java and C++.

## Areas of interest

- data engineering, ETL pipelines, and analytical data models,
- applied AI, computer vision, and image processing,
- backend and domain-driven application development,
- automation, reproducible builds, testing, and CI,
- turning academic concepts into working software.

## Engineering approach

I value projects that are:

- understandable—clear structure and documentation,
- reproducible—documented setup and dependency management,
- verifiable—automated tests or build checks,
- practical—focused on solving a concrete problem.
